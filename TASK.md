# Task

## Goal
Build and maintain a small web application using Go and HTMX.

## Requirements
- Use Go for the server and HTML rendering.
- Use HTMX for interactive UI behavior.
- Keep JavaScript minimal and limited to essential UX functionality.
- Use semantic HTML and organized CSS.
- Add tests for new server behavior when practical.
- Run `gofmt`, `go build .`, and `go test ./...` before completion.

## Notes
- Keep changes focused, simple, and easy to maintain.
- Simple, read-only commands do not require approval.
- Ask for approval before editing, renaming, deleting, staging, or committing files.

Project architecture, development decisions, and roadmap context are maintained in [`docs/PROJECT_CONTEXT.md`](docs/PROJECT_CONTEXT.md).
